# Basic Express App

This project is a modern template for Node.js applications using Express and TypeScript.

## Features

- **TypeScript**: Static typing for safer development.
- **Express**: Minimalist framework for building web applications.
- **Helmet**: Enhances app security by setting HTTP headers.
- **ESLint and Prettier**: Linter and formatter to keep code consistent.
- **Vitest**: Fast and modern testing framework.
- **Husky**: Git hooks to run tasks before commits.
